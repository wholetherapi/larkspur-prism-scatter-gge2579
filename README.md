# Prism Scatter: Neural Radiance Transfer for Sparse-View Remote Sensing

Official implementation of the paper "Prism Scatter: Neural Radiance Transfer for Sparse-View Remote Sensing".

## Overview

This repository contains the reference implementation and the experiment configuration
used in the paper. Code is organised under `src/`, with data preparation notes in `data/`
and analysis notebooks in `notebooks/`.

## Citation

If you use this code in your work, please cite the paper above.
